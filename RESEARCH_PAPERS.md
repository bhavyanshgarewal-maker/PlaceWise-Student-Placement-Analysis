# Research Papers --- PlaceWise

These papers provide background literature for student placement
prediction and data-driven hiring. Their findings are not results from
the PlaceWise project.

## 1. Students' Placement Prediction Using Classification Techniques

-   **Authors:** Sumaira Asif and Tabrez Nafis
-   **Publication:** *International Journal of Computer Sciences and
    Engineering*, 7(4), 289--293 (2019)
-   **DOI:** https://doi.org/10.26438/ijcse/v7i4.289293
-   **Publisher page:**
    https://ijcseonline.org/index.php/j/article/view/4966
-   **Relevance:** Examines J48 decision tree, IBk/K-nearest neighbours,
    and Naive Bayes for student placement prediction using WEKA.

## 2. Student Placement Prediction System using Machine Learning

-   **Authors:** Varsha Kailas Harihar and D. G. Bhalke
-   **Publication:** *SAMRIDDHI: A Journal of Physical Sciences,
    Engineering and Technology*, 12(Suppl. 2), 85--91 (2020)
-   **DOI:** https://doi.org/10.18090/samriddhi.v12iS2.17
-   **Publisher page:**
    https://smsjournals.com/index.php/SAMRIDDHI/article/view/1972
-   **Relevance:** Studies machine-learning classifiers for predicting
    undergraduate placement outcomes.

## 3. Student Placement Chance Prediction Model using Machine Learning Techniques

-   **Authors:** Consult the IEEE Xplore record for the full author
    list.
-   **Publication:** 2021 5th Conference on Information and
    Communication Technology (CICT)
-   **DOI:** https://doi.org/10.1109/CICT53865.2020.9672372
-   **Publisher page:** https://ieeexplore.ieee.org/document/9672372/
-   **Relevance:** Describes an XGBoost-based approach to placement
    prediction using attributes such as academic results, skills,
    training, and projects.

## 4. Predictive Analysis of Campus Placement of Student Using Machine Learning Algorithms

-   **Authors:** Vinod S. Agrawal and Sarika Shelke Kadam
-   **Publication:** *Journal of IoT and Machine Learning*, 1(2), 13--18
    (2024)
-   **DOI:** https://doi.org/10.48001/joitml.2024.1213-18
-   **Publisher page:**
    https://qtanalytics.in/publications/index.php/JoITML/article/view/224
-   **Relevance:** Analyzes machine-learning approaches for predicting
    campus placement from student-related factors.

## 5. Optimizing Student Job Placements with NLP and Explainable AI: A Fair and Transparent Hiring Framework

-   **Authors:** Deepak Kumar, Chaman Verma, and Zoltán Illés
-   **Publication:** *Array*, volume 29, article 100729 (March 2026)
-   **DOI:** https://doi.org/10.1016/j.array.2026.100729
-   **Publisher page:**
    https://www.sciencedirect.com/science/article/pii/S2590005626000524
-   **Relevance:** Discusses a hiring framework combining
    natural-language processing, machine learning, explainability, and
    fairness considerations.

## Relation to PlaceWise

The papers provide context for applying classification and data mining
to student placement analysis. PlaceWise demonstrates a related workflow
using a decision-tree classifier, Naive Bayes, multiple linear
regression, association-rule mining, and K-Means clustering. Describe
PlaceWise's methods and results from its own source code and experiments
rather than copying results from these papers.
